# SCC Examples

These files are generated by [`tools/gen_examples.py`](../../tools/gen_examples.py)
and checked by [`tools/check.py`](../../tools/check.py) (`make check`).
Do not edit them by hand; edit the generator and run `make examples`.

## What is real and what is not

- **Real:** signatures (Ed25519), COSE structures, key thumbprints, EBW URLs
  (derived from the create operations), plaintext and envelope hashes,
  and the TLS encoding of GroupContexts.
- **Demo only:** all keys are derived from fixed labels. Certificates are
  self-signed and marked `DEMO ONLY`.
- **Placeholders:** RFC 3161 timestamp tokens, MLS messages (Commits,
  Welcomes, KeyPackages, PrivateMessages), and the epoch authenticator,
  key commitment, tree hash and transcript hash values. No MLS group was
  run to produce them.
